# Eigen muziek

Zet hier audiobestanden (mp3/m4a/wav) neer waarvoor je de rechten hebt, en maak er een `manifest.json` bij:

```json
[
  { "name": "Mijn track · 128 BPM", "file": "mijn-track.mp3" }
]
```

Ze verschijnen dan in het dropdown "Muziek onder de video" onder "Eigen tracks".
Virale TikTok-sounds zijn auteursrechtelijk beschermd: gebruik alleen tracks uit de Commercial Music Library van TikTok of rechtenvrije/gelicenseerde muziek.
