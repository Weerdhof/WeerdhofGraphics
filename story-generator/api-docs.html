Thumbnail API

For AI assistants and scripts. This page and /api/thumbnail?help=1 describe the same thing; the JSON is the machine-readable version and is built from the live club lists, so it is always current.

Instructions for AI

  • Call GET /api/thumbnail?kind=<kind>&home=<club>&away=<club>&.... A POST with a JSON body takes the same fields.
  • kind is one of shl, shlw, nextmen, nextwomen, lvlm, lvlw.
  • Clubs: the code or the full club name. An unknown club gives HTTP 400 and lists the valid codes.
  • Without json=1 the answer is the image. With json=1 it is JSON with the image URL.
  • Rendered images are stored and can be fetched again at /exports/<name>.
  • HTTP 429 means busy, retry after a few seconds.
